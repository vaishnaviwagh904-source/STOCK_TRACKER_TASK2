# Email Extractor Automation

## Description
Extracts email addresses from a text file and saves them into another file.

## Features
- Reads text file
- Finds all email addresses
- Saves extracted emails

## Technologies Used
- Python
- Regular Expressions

## How to Run
1. Create input.txt
2. Run:
   python email_extractor.py

## Concepts Used
- File Handling
- Regex
- Automation
